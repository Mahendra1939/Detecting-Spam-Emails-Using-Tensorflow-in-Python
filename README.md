📧 Spam Email Detection System
📌 Project Overview

This project is an AI-powered Spam Email Detection System built using Machine Learning, Deep Learning, and Natural Language Processing (NLP).

The system classifies emails or messages as:

Spam
Ham (Not Spam)

The model analyzes text patterns and predicts whether a message is unwanted or genuine.

🚀 Features

✅ Spam and Ham Classification
✅ NLP-Based Text Processing
✅ Deep Learning Model using TensorFlow
✅ Tokenization and Sequence Padding
✅ Real-Time Message Prediction
✅ Streamlit Web Application
